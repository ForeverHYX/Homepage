# ACM artifact badges

The JPEG files are the unmodified badge images published by ACM on its
[Artifact Review and Badging](https://www.acm.org/publications/policies/artifact-review-and-badging-current)
policy page:

- `artifacts_available.jpg`
- `artifacts_evaluated_functional.jpg`
- `results_reproduced.jpg`

The matching PNG files preserve that artwork and palette while replacing only
the white background with transparency for the website. Keep the artwork and
its official colors unchanged. Presentation sizing and layout belong in
`static/css/src/35-publication-badges.css`.
